# code-guilty
A detective mystery game built using Java OOP concepts and a custom interface. Players investigate dynamically generated murder cases by interrogating suspects, examining evidence, tracking clues, and identifying the culprit through logical deduction. The project uses multithreading, exception handling, collections, and concurrent programming.

# Overview
CODE: GUILTY is an interactive detective game where players solve randomly generated murder cases. Every case contains suspects, evidence, alibis, and hidden clues. The player must gather information, increase suspicion scores, and make an accusation before closing the case.

# Features
* Dynamic case generation
* Random suspects and personalities
* Evidence-based investigation system
* Suspicion score tracking
* Detective notebook for logging actions
* Hint system
* Scoring and time bonus system
* Interactive interrogations
* Multithreaded animations and hints
* Custom exception handling
* Modern detective-themed web interface
* OOP Concepts Used
    1. Inheritance
    2. Encapsulation
    3. Abstraction
    4. Polymorphism
* Multithreading :The project includes several custom threads:
    1. TypewriterThread
    2. SpinnerThread
    3. HintThread
* ExecutorService
* Exception Handling
* Collections Used for:
    1. Suspect storage
    2. Evidence storage
    3. Notebook entries
    4. Randomized case generation
